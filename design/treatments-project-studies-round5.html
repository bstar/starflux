One project. The whole working space.

Run your agent. Keep shells in terminal tabs. Launch the app you’re building and its supporting apps in a virtual desktop. Everything belongs to a project, locally or over SSH.

01 / Project container

A location and its working state

A project owns its directory, host, agent, terminals and virtual desktop. Switching projects restores that project’s selected space and windows.

03 / Terminals

Shells when you need them

Build logs, commands and a spare shell live in tabs. An explicit split can show two shells; changing tabs never creates a split.

The app and everything around it

Run the project’s app, then add a browser, file manager or another app. Arrange their windows in the project’s virtual desktop on a local or SSH host.
