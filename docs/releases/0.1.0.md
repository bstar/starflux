STAR/FLUX 0.1.0 is the first packaged release of the project workspace, with native Kitty terminal rendering, multiple concurrent agents, persistent local/SSH sessions, shared app desktops, video and audio transport, and project Git/activity tracking.

Downloads:
- **Linux x86_64 / ARM64:** choose the matching `.AppImage`, make it executable, and run it from Kitty. Built against glibc 2.31. Without FUSE, use `APPIMAGE_EXTRACT_AND_RUN=1 ./starflux-*.AppImage`.
- **Arch Linux x86_64:** install the `.pkg.tar.zst` with `sudo pacman -U`. The matching source archive and `PKGBUILD` are included.
- **Apple Silicon:** the `starflux-client` archive is the presentation client for a Linux workspace host. Requires Kitty and Homebrew FFmpeg; follow its `INSTALL.txt`.

The Linux AppImage carries matching PTY helpers, Python, tmux, GStreamer and audio capture tools. Graphical app hosts need Xwayland, X keyboard data, D-Bus and functioning host graphics drivers; app audio needs a running PulseAudio-compatible server. The presenting terminal must be Kitty with the STAR/KIT watcher installed for remote presentation. A plain SSH shell in PowerShell does not provide Kitty graphics or native cell presentation.

Workspaces persist after the UI closes. The AppImage stages its runtime in a private, content-addressed cache so those processes can continue using their matching helpers. Do not remove that cache while its sessions are running. Reopen named workspaces with `--workspace NAME`; use `--stop` only when you intend to end them.

`SHA256SUMS` covers the exact downloadable artifact bytes. Build results are linked from the README status badges. This is an initial release; clean-distribution smoke checks verify bundled tools and headless video encoding, while GPU, audio devices and desktop integration depend on the host setup.
