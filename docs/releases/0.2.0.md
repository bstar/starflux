STAR/FLUX 0.2.0 introduces the new project name, a full cells interface, and more responsive graphical app streaming.

Changes:

- Run `starflux --cells` in an ordinary terminal, locally or over SSH. Project management, splits, selection, context menus, file delivery, refresh and persistent sessions share the graphical workspace model. App Space controls appear only in capable graphical views.
- Project rows are selectable across their full width and have a subtle hover background. Add project sits at the bottom; project closing is available through the context menu.
- Native terminal panes fill their space, including newly opened splits. Hidden tabs no longer shrink visible terminals. Scrollback remains available while agents generate plans or wait for approval.
- Graphical chrome is cropped and cached. App video keeps raw frames replaceable until the viewer has room, reducing cursor delay without changing a game's canvas-drawn cursor.
- App Space is capped at 1920×1080 and displayed at 1:1 size. Larger windows do not stretch it; smaller simultaneous viewers crop the shared desktop. Automatic video adaptation preserves resolution.
- Capable clients use buffered PCM-v2 audio playback alongside bounded H.264 video.
- Transferred PTY sessions apply output backpressure instead of disconnecting during large bursts. Dead presentation bridges reconnect without restarting their original sessions.
- Activity detection ignores quoted old working messages and re-checks the current footer for retained sessions.

Downloads:

- **Linux x86_64 / ARM64:** choose the matching `starflux-0.2.0-ARCH.AppImage`, make it executable, and run it. Without FUSE, use `APPIMAGE_EXTRACT_AND_RUN=1`. The Linux packages include the workspace host and cells frontend; graphical presentation uses Kitty and the STAR/KIT integration.
- **Arch Linux x86_64:** install the `.pkg.tar.zst` with `sudo pacman -U`. The matching source archive and `PKGBUILD` are included.
- **Apple Silicon:** the `starflux-client-0.2.0-aarch64-apple-darwin.tar.gz` archive contains the presentation client for a Linux workspace host. It requires Kitty and Homebrew FFmpeg; follow its `INSTALL.txt`.

Graphical app hosts need Xwayland, X keyboard data, D-Bus and functioning graphics drivers. App audio requires PulseAudio or PipeWire-Pulse. Cells mode does not require a graphical desktop or Kitty.

Upgrade notes:

The application, command, package, data and runtime namespaces are now `starflux`. Back up existing project metadata before upgrading a 0.1.x installation under the former name. Existing metadata and saved executable paths need migration; this release does not automatically rename a live installation. Keep the original runtime, matching helpers and any compatibility links until its sessions have finished. Do not remove an AppImage's durable runtime cache while sessions are running.

Closing a view retains its workspace processes. Reopen with `--workspace NAME`; use `--stop` only when you intend to end that project's processes.

`SHA256SUMS` covers the exact downloadable artifact bytes. Publication follows the Linux release checks, Arch installation checks, Apple Silicon client build, and AppImage clean-distribution/FUSE checks. GPU behavior, physical audio playback and WAN latency still depend on the host and presenting device.
